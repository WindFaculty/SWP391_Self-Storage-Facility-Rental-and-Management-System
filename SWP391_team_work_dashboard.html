Shared rules

Quy tắc chung của cả team

Git workflow

  • Không code trực tiếp trên main
  • Feature branch → update main → resolve conflict → test → PR → review → CI PASS → merge
  • Sau mỗi merge: git fetch origin + git rebase origin/main
  • Không để branch lệch main quá lâu

Shared code

  • common/ và config/ là shared ownership
  • ApiResponse.java
  • GlobalExceptionHandler.java
  • BaseEntity.java
  • SecurityConfig.java
  • application.yml
  • pom.xml
  • Muốn sửa shared file → PR nhỏ riêng

Main protection

  • No direct push to main
  • Pull Request required
  • CI required
  • Minimum 1 reviewer
  • Không git push --force main
